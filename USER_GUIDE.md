# User Guide — Executive Command & Value Intelligence Platform

## 1. Executive Command Center (`/business/portfolio`)
The Command Center provides a high-level executive dashboard tracking total portfolio ROI (+215%), net realized savings ($4.94M), active initiatives count, and overall risk posture.

---

## 2. Initiatives Directory (`/business/initiatives`)
- Create new AI initiatives using the 5-step wizard.
- View initiatives table with search, status filters, and business area filters.
- Open detail views (`/business/initiatives/{id}`) to inspect objectives, financial costs, and audit events.

---

## 3. AI Value Studio (`/business/ai-studio`)
- Analyze initiatives using provider-agnostic AI engines.
- Inspect deep-dive explainability panels for confidence scores and risk breakdowns.

---

## 4. Governance Approval Center (`/business/approvals`)
- Review pending initiative gates in the approval queue.
- Execute decision actions (`APPROVE`, `REJECT`, `REQUEST_CHANGES`, `ESCALATE`) with audit trail tracking.
